## 最初に読む範囲

1. [全体の文書入口](../../overview/README.md)と repository の AGENTS.md を読む。
2. 比較計画の「現行との差分」「比較する三つのプリセット」、ホストと全アプリの設計、「実装順」を読み、サンプル画像で配置の違いを確認する。
3. 実装詳細 §1 で手元の版を照合し、§6 の一行を選ぶ。起動・入力・テーマの共通契約は比較計画から参照する。
4. 実機で比較する前に、評価手順の必須条件と記録欄を確認する。

新計画は **手首の近くに置く円盤状の quick menu** を共通の入口にし、詳細一覧の呼び出し・配置を
三案で比較します。円／六角形は別のテーマ軸です。操作方式の採用と skin の採用を混同しません。

どの案も、一覧・お気に入り・自由配置した起動ボタン・drag-out に対象ホストを明示します。
お気に入りの有無や棚の置き場所によらず、手首メニューなどの入口から **すべてのアプリ** を開けることを
共通要件にします。最初に Ubuntu Desktop 1 台の実メニューを開くたびに更新し、未検証・非対応を含む全項目を選べるようにします。次に同じホストで 2 アプリを並行利用し、個別に入力・終了・回収できることを確かめます。複数ホストの登録・横断検索は後続です。

コードの存在、Host/JVM 試験、Android build、Quest での手入力・使いやすさは別々に記録します。
利用者が同一 APK で P1・P2・P3 を試し、残したい案を選びます。不要と判断した案を削除する際に、古い保存設定を移行します。
