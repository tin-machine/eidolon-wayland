# Phase 5の最終実機確認

自動SDK検査の合成key/ray、ImageReader検査、装着者の確認を別に記録する。
この文書の手動項目は、回答を得るまで未受入れとする。入力した本文・室内画像を作業ログへ収集しない。

## 表示・配置

1. 最新Buildの「ターミナルを開く」を二回押す。二枚の文字が読め、片方をクリックすると入力先が切り替わることを確認する。
2. 「現実を背景に」「単色の背景に」を切り替える。パネルを保ったまま背景だけが変わることを確認する。
3. 一枚を選択して800×600／1280×720と「標準表示」「大きく表示」を試す。文字の欠けや、クリック位置のずれがないことを確認する。
4. 「配置を編集」でグリップ移動・角度変更を行い、「配置を確定して入力へ戻る」。編集時の移動操作がterminalの入力にならず、確定後は文字入力へ戻ることを確認する。
5. 一枚だけにして配置・背景・配列を選び、「接続を閉じる」→「ターミナルを開く」で復元を確認する。同じapp_idのfootを複数開いた場合の配置は接続内に保持し、永続配置とは区別する。

## 物理キーボード・コントローラー

Questへ実際のキーボードを接続し、terminalを選択して行う。ADB inputや合成イベントで代用しない。

1. shellで英数・記号・Tab・Backspace・矢印を試す。Ctrl+A/E/L、Alt+B/F、長押しrepeatと離した後の停止を確認する。選択したUS/JISと実キーボードの種類も報告する。
2. `nvim --clean`で挿入・Esc・矢印を試し、`:q!`で終了する。F5/F12等は`cat -v`で届くsequenceを目視し、Ctrl+Dで戻る。
3. `tmux -L eidolon-phase5-manual -f /dev/null new-session -s verify`でCtrl+Bからの操作を確認する。終了は各shellの`exit`。既存の通常tmux serverは使わない。
4. controllerのクリック・文字選択drag・scrollを試す。二枚間の移動、パネル外へ出た後のreleaseで押下が残らないことを確認する。
5. 固定の無害な文字列を選択しCtrl+Shift+Cでcopy、もう一枚でCtrl+Shift+Vを試す。文字列の内容はログへ送らず、一致したかだけを報告する。
6. Shift等を保持したままOS Menuへ移動し、キーを離してアプリへ戻る。小文字入力へ戻り、押下が残らないことを確認する。通常のsleep→復帰後も入力・描画を確認する。

tmux 3.8／Neovim 0.12.6は固定版を`apt-get --no-upgrade install --no-install-recommends`で準備した。
18 packageを追加し、既存packageの更新・削除はなかった。foot 1.28.0／Waypipe 0.11.3を維持した。
版と依存の導入記録、Neovimのclean headless起動結果はprivate作業ログに保存した。
これはHMDでの文字表示や物理キーの成功を証明するものではない。
